# Flipwise — роадмап

Цель: веб-приложение для карточек удобнее Quizlet. Этапы идут по порядку; внутри этапа — в любом порядке.
Каждый пункт — отдельная ветка `feat/*` и PR.

## Этап 1. Быстрые улучшения UX

- [x] Кнопка «Добавить карточку» всегда видна в редакторе (фиксированная внизу); Enter в последнем поле создаёт новую карточку и ставит в неё фокус
- [x] ⭐ Избранное на карточках
- [x] Перед учёбой выбор набора: «Все / Незнакомые / Избранные» + размер сессии (сейчас Flashcards всегда стартует со всей колоды, хотя `flash: 'known'` уже хранится)
- [x] Горячие клавиши в учёбе: пробел — перевернуть, ← / → — «не знаю / знаю»
- [x] Предупреждение о дубликатах при добавлении карточки
- [x] Поиск по всем колодам
- [x] Список «Трудные слова» (больше всего ошибок, по `progress.wrong`)

## Этап 2. Режим «Предложения» (без ИИ во время учёбы)

- [x] Во Flashcards переключатель «Слова / Предложения»: спереди — русское предложение с выделенным словом, сзади — оригинал + озвучка; ответ «знаю / не знаю»
- [x] Кнопка «Примеры для всей колоды» — генерация пачками (~10 карточек в одном запросе)
- [x] Выбор уровня (A1–C2) прямо в листе примеров; ужесточить промпт под CEFR
- [x] Для Anthropic: `effort: low` (у Haiku 5.5 по умолчанию `medium` — лишние токены на размышления)

## Отложено

- Автозаполнение карточки ИИ (перевод, часть речи, транскрипция) — пока руками; стоит ~$0.0003 за карточку, можно вернуться
- Оплата за «Ключ Flipwise» — после этапа 5, через тот же прокси

## Не делаем

- Синхронизация с Quizlet — публичного API нет
- Распознавание произношения

## Заметки к решениям

**Стоимость ИИ** (Claude Haiku 5.5: $0.10 / $0.50 за 1M токенов вход / выход):

| Действие                        | ≈ за раз      | Частота                                      |
| ------------------------------- | ------------- | -------------------------------------------- |
| 3 примера к карточке            | $0.0005       | один раз на карточку (кэш в `card.examples`) |
| Проверка перевода               | $0.0004       | на каждый спорный ответ                      |
| История / мнемоника / «почему?» | $0.0003–0.001 | по кнопке                                    |

Дороже всего то, что вызывается на каждый ответ, а не разовая генерация.

**Dexie Cloud:**

- Бесплатно: 3 постоянных пользователя; «пробные» перестают синхронизироваться после 30 активных дней. Платно — €0.12 / пользователь / мес (≈ €3 за 25 мест).
- Риски: маленький вендор; при офлайн-правке на двух устройствах счётчики `correct` / `wrong` могут терять прибавления.
- Путь миграции: (1) свой сервер Dexie Cloud — разовая лицензия €3,495, клиент не меняется; (2) `npx dexie-cloud export` → Supabase / Postgres, Dexie остаётся локальным кэшем, меняется только слой синхронизации.

**Общий ключ:** в клиентский код класть нельзя (сайт публичный) — только через прокси.
